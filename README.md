# react-app-template

[![Run Tests](https://github.com/Syhlex/react-app-template/actions/workflows/tests.yml/badge.svg)](https://github.com/Syhlex/react-app-template/actions/workflows/tests.yml)

Starter template for React projects using TypeScript, Sass with CSS modules, Vitest, and Vite.

Built as a personalized, lightweight alternative to Create React App.

## Scripts

| Command                   | Description                          |
| ------------------------- | ------------------------------------ |
| `npm run setup-git-hooks` | Setup git hooks                      |
| `npm run dev`             | Start the development server         |
| `npm run build`           | Build for production                 |
| `npm test`                | Run tests                            |
| `npm run lint`            | Lint source files                    |
| `npm run clear`           | Remove build output and node_modules |
