# CLAUDE.md

- Run `npm run check` (format, lint, typecheck, test, build) before calling work done. The pre-commit hook only checks; run `npm run format` to fix formatting.
- Don't add a state management or data-fetching library without asking.
- Shared UI used by two or more features goes in `src/components/<Component>/`; feature-only code stays in `src/features/<feature>/`.
- Network requests live in `src/api/` as plain async functions. Components don't call `fetch` directly; load page data through route `loader`s.
- Keep hooks thin: they manage state and effects, and business rules go in pure functions that can be tested without rendering.
- `*.module.d.scss.ts` files are generated by `vite-plugin-sass-dts` and gitignored; don't edit or create them.
- Never hardcode user-facing strings. When adding a `<feature>.i18n.ts` file, register it in `src/i18n/translations.ts` for every locale.
